БОТ ДЛЯ СОЗДАНИЯ ПРОЕКТОВ

В этом телеграм боте вы можете использовать команду /new_projects чтобы добавить свои проекты в бота и показывать их другим пользователям.

Бот удобен для использования! Чтобы начать использовать бота будет приведина инструкция ниже!

1. Скачайте файлы бота и поместите в свою папку
2. Установите все нужные библеотеки - pyTelegramBotAPI
3. После того как установили все нужное, зайдите в файл config.py и в переменную TOKEN введите токен от вашего бота, который можно получить у @BotFather
4. После того как вы ввели свой токен бота, запустите бота используя файл bot.py
5. Теперь введите в телеграм боте команду /info и используйте бота

Приятного использования!
